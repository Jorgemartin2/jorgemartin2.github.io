### AcheTu

Projeto experimental de **verificação local de credenciais presentes em uma wordlist**, desenvolvido para estudos relacionados à exposição de credenciais e segurança de senhas.

A aplicação realiza a consulta **localmente no navegador**, sem enviar a senha pesquisada para APIs externas.

> O projeto é destinado a fins educacionais e de pesquisa em segurança da informação.
